# Análise de Qualidade - WhatsApp

## Sobre o projeto

Este repositório contém um trabalho desenvolvido durante meus estudos de Quality Assurance (QA) na EBAC.

O objetivo da atividade foi analisar a qualidade de um produto ou serviço que utilizo no dia a dia. Para isso, escolhi o WhatsApp, um aplicativo de mensagens que uso com frequência.

A análise foi baseada na minha experiência como usuário, observando seu funcionamento, facilidade de uso e outros pontos importantes para avaliar sua qualidade.

## Características analisadas

- **Usabilidade:** facilidade para utilizar as principais funcionalidades.
- **Matéria-prima:** recursos necessários para o funcionamento do aplicativo.
- **Performance:** desempenho e estabilidade durante o uso.
- **Design:** organização das telas, cores e ícones.
- **Durabilidade:** atualizações e compatibilidade com os dispositivos.

## Resultado da análise

No geral, minha experiência com o WhatsApp foi positiva. O aplicativo apresentou bom desempenho, facilidade de uso e não identifiquei problemas significativos durante minha utilização.

A atividade também me ajudou a entender melhor a importância de avaliar um produto de forma crítica, observando detalhes que normalmente passam despercebidos.
